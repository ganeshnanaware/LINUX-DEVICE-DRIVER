Q2. Given an unsorted array of N integers and an integer K, find the minimum number of swaps required to bring all elements less than or equal to K together in one contiguous group.
Any two array elements may be swapped, regardless of their positions.

Sample Input
N = 8
Array = [2, 1, 5, 6, 3, 7, 4, 8]
K = 4

Expected Output
Minimum swaps = 2

Explanation
There are four elements ≤ 4: 2, 1, 3, 4.
We need to find a window of length 4 containing the minimum number of elements greater than 4. Each such unwanted element can be replaced with one required element outside the window using one swap.

Constraints

1 ≤ N ≤ 100,000

Target time complexity: O(N)

Target extra space: O(1)
